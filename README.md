# Хүнд даацын техник төв

Static вэбсайт (HTML + Tailwind CDN). Build хийх шаардлагагүй.

## GitHub Pages дээр байршуулах
1. Энэ хавтсыг GitHub repository руу push хийнэ.
2. **Settings → Pages → Source: GitHub Actions** сонгоно.
3. `main` branch руу push хийх бүрт сайт автоматаар шинэчлэгдэнэ.

Сайт: `https://<username>.github.io/<repo>/`
